# План: Telegram → VK Bot (пересылка сообщений)

## Обзор

Python-бот, который отслеживает новый контент в Telegram-канале и автоматически публикует его в VK-сообществе (текст + фотографии).

## Архитектура

```
Telegram Channel → Bot (python-telegram-bot) → Transform → VK Community (vk-api + longpoll)
```

## Компоненты

### 1. Структура проекта

```
tg2vk-bot/
├── main.py              # Точка входа, запуск бота
├── config.py            # Загрузка конфигурации из .env
├── tg_listener.py       # Подключение к Telegram, мониторинг канала
├── vk_publisher.py      # Публикация в VK (текст + фото)
├── vk_longpoll.py       # VK Longpoll сервер для проверки статуса публикаций
├── utils.py             # Вспомогательные функции (скачивание фото, обработка текста)
├── requirements.txt     # Зависимости
├── .env.example         # Шаблон конфигурации
└── README.md            # Инструкция по развёртыванию
```

### 2. Зависимости (requirements.txt)

- `python-telegram-bot==20.7` — работа с Telegram API
- `vk-api==5.131` — работа с VK API
- `aiohttp==3.9.1` — асинхронные HTTP-запросы
- `Pillow==10.1.0` — обработка изображений
- `python-dotenv==1.0.0` — загрузка переменных окружения
- `aiofiles==23.2.1` — асинхронная работа с файлами

### 3. Конфигурация (.env)

```env
# Telegram
TG_BOT_TOKEN=your_bot_token_here
TG_CHANNEL_ID=@channel_username или -100xxxxxxxxxx

# VK
VK_COMMUNITY_TOKEN=group_token_здесь
VK_GROUP_ID=id_сообщества

# Настройки бота
LOG_LEVEL=INFO
WORKING_DIR=./tmp
```

### 4. Логика работы

#### Telegram Listener (`tg_listener.py`)
- Подключение через `Application.builder().token(TG_BOT_TOKEN).build()`
- Подписка на обновления канала через `channel_post_handler`
- Фильтрация: только новые сообщения (не редактированные)
- Извлечение: текст сообщения + вложенные фотографии
- Отправка обработанных данных в VK через очередь

#### VK Publisher (`vk_publisher.py`)
- Инициализация `vk.Session(access_token=VK_COMMUNITY_TOKEN)`
- Публикация текста через `wall.post()`
- Загрузка фото через `wall.savePhotosServer()` → `wall.publish()`
- Обработка ошибок с повторными попытками (retry logic)
- Логирование успешных/неуспешных публикаций

#### Обработка медиа (`utils.py`)
- Скачивание фотографий из Telegram через `download()` из python-telegram-bot
- Сохранение во временную директорию
- Оптимизация размера через Pillow (макс. 1920px по длинной стороне)
- Загрузка в VK через multipart upload

#### Обработка текста (`utils.py`)
- Очистка от лишних пробелов и переносов
- Сохранение форматирования (жирный, курсив) — конвертация в VK-формат
- Обработка ссылок и упоминаний
- Ограничение длины (VK: до 2048 символов)

### 5. Обработка ошибок

- **Telegram:** повторное подключение при разрыве (built-in в python-telegram-bot)
- **VK:** retry с экспоненциальной задержкой (3 попытки)
- **Rate limiting:** VK — 3 запроса/сек, TG — 30 сообщений/сек (после получения)
- **Дубликаты:** хранение ID опубликованных TG-сообщений в файле/базе
- **Логирование:** все действия записываются в лог-файл

### 6. Развёртывание на VPS

- Python 3.10+
- systemd service для автозапуска
- Логирование в journalctl
- Автоматический рестарт при падении

## Важные нюансы

- VK Longpoll используется для проверки статуса публикаций (успешно/ошибка)
- Бот должен иметь права на публикацию в VK-сообществе
- Для фото в VK: загрузка через temporary server метод (upload URL → POST → savePhotosServer)
- Telegram channel_id должен быть в формате `-100xxxxxxxxxx` (для ботов)
- Медиа-контент (видео, голосовые) игнорируется согласно выбору пользователя
