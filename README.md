# TG2VK Bot

Бот для автоматической пересылки сообщений из Telegram-канала в VK-сообщество.

## Возможности

- Автоматическая публикация новых сообщений из TG-канала в VK
- Поддержка текста и фотографий
- Защита от дубликатов
- Rate limiting для VK API (3 запроса/сек)
- Retry logic при ошибках
- Логирование всех действий

## Требования

- Python 3.10+
- Токен Telegram-бота (от @BotFather)
- Токен группы VK с правами на публикацию

## Установка

### 1. Клонирование и настройка

```powershell
# Создание директории проекта
mkdir tg2vk-bot
cd tg2vk-bot

# Копирование файлов проекта
# (скопируйте все файлы из репозитория)

# Создание виртуального окружения
python -m venv venv
.\venv\Scripts\Activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка конфигурации

```powershell
# Копирование примера конфигурации
copy .env.example .env

# Редактирование .env
notepad .env
```

Заполните параметры:

```env
# Telegram
TG_BOT_TOKEN=your_bot_token_here
TG_CHANNEL_ID=-100xxxxxxxxxx

# VK (токен группы с правами на публикацию)
VK_COMMUNITY_TOKEN=group_token_здесь
VK_GROUP_ID=id_сообщества

# Настройки
LOG_LEVEL=INFO
WORKING_DIR=./tmp
```

### 3. Настройка Telegram-бота

1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`
5. Добавьте бота в канал как администратора

### 4. Настройка VK

1. Создайте сообщество (группу/канал)
2. Включите API в настройках сообщества
3. Получите токен с правами на публикацию
   - Через [VK Developer Portal](https://dev.vk.com/)
   - Или через [VK Community Token Generator](https://vk.com@apps.vk.com/me)
4. Убедитесь, что бот имеет права на публикацию в группе

## Запуск

```powershell
# Активация виртуального окружения
.\venv\Scripts\Activate

# Запуск бота
python main.py
```

Для остановки нажмите `Ctrl+C`. Бот автоматически сохранит список опубликованных сообщений.

## Логирование

Все действия бота записываются в:
- `logs/bot.log` — файл логов
- `stdout` — консоль

## Обработка ошибок

- **Telegram:** автоматическое повторное подключение при разрыве
- **VK:** retry с экспоненциальной задержкой (3 попытки)
- **Rate limiting:** соблюдение лимитов VK API
- **Дубликаты:** хранение ID опубликованных сообщений в файле
- **Медиа:** игнорирование видео и голосовых сообщений

## Troubleshooting

### Бот не публикует в VK

1. Проверьте токен в `.env`
2. Убедитесь, что у токена есть права на публикацию
3. Проверьте логи: `type logs\bot.log`

### Ошибка "API error"

1. Проверьте лимиты VK API (3 запроса/сек)
2. Убедитесь, что группа не заблокирована
3. Проверьте формат channel_id (должен быть `-100xxxxxxxxxx`)

### Бот не запускается

1. Проверьте Python версию: `python --version` (нужно 3.10+)
2. Проверьте зависимости: `pip install -r requirements.txt`
3. Проверьте права на запись в рабочую директорию
